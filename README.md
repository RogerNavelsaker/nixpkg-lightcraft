# nixpkg-lightcraft

Nix package for [ArtCraft LightCraft](https://github.com/storytold/lightcraft), using its official Linux x86_64 release archive. The package installs the app directly; it does not include the ArtCraft launcher or provide an auto-updater.

Pinned upstream release: `v0.13.0`.

```sh
nix build
nix run
```
